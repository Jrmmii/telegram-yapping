# Telegram Yapping Skill

A safety-first, permission-based workflow for creating Telegram group reply assistants, with opt-in behavior, language checks, rate-limit compliance, and credential hygiene.

This repository is a skill guide. It does not include an account session, API credentials, group identifiers, or an operational bot instance.

## Install in Hermes Agent

Copy `SKILL.md` into a skill directory, for example:

```text
~/.hermes/skills/telegram-yapping/SKILL.md
```

See `SKILL.md` for setup, safe operation, testing, and public-repository hygiene.
